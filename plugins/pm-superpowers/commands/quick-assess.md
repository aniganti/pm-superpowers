# Quick Competitive Assessment

Run a focused competitive landscape analysis:

1. Gather product/company context and known competitors from the PM
2. Spawn the `competitive-researcher` agent for real-time market intelligence
3. Produce competitor profiles, value chain mapping, and positioning analysis

## Usage

```
/pm-superpowers:quick-assess [product or company name]
```

## What You Get

A competitive intelligence brief with:
- Competitor profiles table (positioning, strengths, weaknesses, recent moves)
- Value chain mapping (suppliers, distributors, consumers)
- Positioning map on key dimensions
- Differentiation gaps and whitespace opportunities

## When to Use This vs the Strategy Skill

- Use `/quick-assess` when you need a fast competitive read — maybe before a stakeholder meeting or to validate assumptions about competitors
- Use the `strategy` skill when you need the full 6-step product strategy analysis
